============================================================================
              نظام نقاط البيع وإدارة المخزون (POS System)
                     دليل التشغيل للعميل (Offline)
============================================================================

1. متطلبات التشغيل على جهاز العميل:
----------------------------------------------------------------------------
- نظام تشغيل: Windows 10 أو Windows 11 أو Windows Server.
- حزمة .NET Framework 4.8.1 (مدمجة تلقائياً في ويندوز 10 و 11 الحديثة).
- خادم قواعد بيانات محلي (يعمل بدون إنترنت تماماً):
  * إما Microsoft SQL Server Express (مجاني)
  * أو Microsoft SQL Server LocalDB

2. خطوات التثبيت والتشغيل لأول مرة:
----------------------------------------------------------------------------
الخطوة (1): اضغط مرتين على ملف "1-تثبيت_قاعدة_البيانات.bat"
  - سيقوم السكربت تلقائياً باكتشاف خادم SQL، وإنشاء قاعدة البيانات (POS_DB)،
    وإنشاء كافة الجداول وتغذيتها بالبيانات الأولية، وضبط إعدادات الاتصال.

الخطوة (2): اضغط مرتين على ملف "POS.exe" أو "2-تشغيل_البرنامج.bat"
  - سيفتح النظام شاشة تسجيل الدخول مباشرة.

3. بيانات تسجيل الدخول الافتراضية:
----------------------------------------------------------------------------
- اسم المستخدم (Username): admin
- كلمة المرور   (Password): admin123

(أو يمكنك الدخول بحساب كاشير: cashier1 / cashier123)

4. في حال تغيير خادم SQL يدوياً:
----------------------------------------------------------------------------
يمكنك فتح ملف POS.exe.config بالمفكرة وتعديل سطر الاتصال:
connectionString="Data Source=.\SQLEXPRESS;Initial Catalog=POS_DB;Integrated Security=True;"
============================================================================
